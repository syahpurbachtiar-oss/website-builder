Kisah Nyala Api Jelajah

Jakarta, Indonesia — sejak 1961

MONAS

132 meter menjulang di jantung Jakarta — dituangkan dalam marmer Lampung, disepuh lidah api dari 35 kg emas. Gulir ke bawah untuk mendekat.

gulir
Kisah — 01

Dituangkan dari perjuangan, bukan sekadar batu.

Diresmikan pembangunannya oleh Presiden Soekarno pada 17 Agustus 1961, Monas berdiri sebagai tugu peringatan perjuangan kemerdekaan Indonesia. Bentuknya — alu dan lesung — diambil dari alat rumah tangga leluhur: lambang kesuburan dan ketahanan.

Di kaki tugu, relief diorama membentang mengelilingi ruang museum, menuturkan perjalanan bangsa dari masa kerajaan hingga proklamasi.

Kisah — 02

Lidah Api Kemerdekaan.

Di puncaknya, cawan perunggu menopang lidah api setinggi 14 meter, disepuh lembaran emas seberat sekitar 35 kilogram — diperbarui dan ditambah emasnya menjelang peringatan kemerdekaan ke-50 pada 1995.

Nyala ini tak pernah padam dalam makna: simbol semangat juang yang terus menyala.
